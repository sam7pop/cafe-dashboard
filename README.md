لوحة تحكم بتخلي صاحب الكافيه أو المطعم يتابع محله من الموبايل وهو مش موجود.

مميزات اللوحة:
- ملخص فوري: المبيعات، وعدد الفواتير، ومتوسط الفاتورة، وعجز الدرج
- رسم بياني للمبيعات بالساعة أو باليوم، مع التفاصيل عند الوقوف على أي عمود
- تنبيهات ملوّنة حسب الأهمية: عجز الدرج، والإلغاءات الكتير، والخصومات من غير موافقة، والإلغاء بعد الدفع
- مقارنة أداء الكاشيرات بتقييم واضح (ممتاز / متابعة / مراجعة عاجلة)
- الأصناف الأكثر مبيعاً، ونسبة الكاش مقابل الفيزا
- التبديل بين النهارده وآخر 7 أيام والشهر بضغطة واحدة
- تصميم عربي يشتغل على الكمبيوتر والموبايل، وبيدعم الوضع الليلي

العمل مبني ببيانات وهمية للعرض، وقابل للربط ببيانات أي نظام كاشير.
